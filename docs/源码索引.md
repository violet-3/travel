# 当前架构与源码索引

## 当前默认入口

```text
Web: app.py → POST /api/generate 或 /api/generate/stream
CLI: main.py → orchestrator_llm.TravelOrchestrator
```

两种入口都使用 LangChain 主链；`orchestrator.py` 与 `tools/dify_client.py` 是保留的旧 Dify 实现，不会被当前 Web/CLI 隐式调用。

| 模块 | 源码 | 当前职责 |

| Web API | `app.py` | 本机 FastAPI、模型/地图设置、NDJSON 生成、历史和导出 |

## 当前 HTTP 契约

| API | 行为 |
|---|---|
| `POST /api/generate` | 返回完整攻略 JSON |
| `POST /api/generate/stream` | NDJSON `progress` 后跟一个 `guide` 或 `error` 终态；断连会取消后台任务 |
| `/api/model-profiles` | 本机模型档案元数据；Key 不写入响应 |
| `/api/amap-settings` | 地图服务配置状态；Key 不回显 |
| `/api/history` | 最近攻略摘要与单条读取/删除 |
| `POST /api/export/markdown` | 将已生成攻略编译为 Markdown 下载 |
| `GET /api/cache` | 短时缓存条目数与 TTL |
| `DELETE /api/cache` | 清空短时缓存 |

前端使用 `generation_stream.js` 校验分块 UTF-8 NDJSON、终止事件和坏流清理。当前接口不是 WebSocket。

`TravelGuide` 在十轮基础上增加 `feasibility`（第12轮）、`prep`（第13轮）、`quality`（第14轮）、`cache_hit` / `cache_age_seconds`（第15轮）等字段；`Spot.ticket_status` 区分未知、模型参考价和模型标记免费，`BudgetBreakdown` 显示待核价活动、门票拆分、住宿系数与费用占比。详见[第16—18轮验收](05-研发协作/落地复核与第十六至十八轮验收.md)。

## 运行与版本

```bash
python -m pip install -r requirements.txt
python -X utf8 app.py
python -X utf8 main.py "想去安阳玩3天" --save
python -X utf8 main.py --check
```

Python 最低版本为 3.10。可复现的 Windows/Python 3.10 依赖快照见仓库根目录 `requirements-lock-py310-win.txt`；其它平台使用 `requirements.txt`。项目当前没有单独的应用版本号，按 Git 工作区/commit 识别源码版本。

## 历史 Dify 文档说明

早期文档中的 Dify 工作流、知识库、WebSocket、Obsidian 和媒体视频搜索是旧实现或设计目标。Dify 旧链路保留在上述源码位置；当前主链使用 LangChain Agent，并增加 Pydantic 校验、用户级配置、高德服务、天气、图片缓存、本地历史和 Markdown/JSON/打印输出。两条链路的功能不等价，具体见[研发协作记录](05-研发协作/README.md#dify-历史链路与-langchain-主链)。
