## 🔧 快速启动

```bash
# 1. 复制 .env.example 为 .env，填入 Dify / 高德 Key
# 2. 安装依赖
pip install -r requirements.txt
# 3. Web 界面
python app.py          # http://localhost:8000
# 或 CLI
python main.py "想去安阳玩3天" [--direct] [--save]
```
