# 当前图片与地点匹配流程

> 当前实现由 `tools/enrich.py` 完成。早期文档中的 Unsplash、小红书、百度图片、视频搜索和 Obsidian 附件搬运没有接入当前主链。

## 当前降级顺序

```text
新鲜且完整的本地文件
  → 高德 POI 图片
  → 可选 Wikimedia Commons
  → 高德静态位置示意图
  → 无图时显示仓库本地占位图
```

高德 POI 图片、Wikimedia 与静态地图都需要对应的服务可用性、坐标/图片数据和有效配置；任何一步都可能没有结果。静态地图标注为位置示意图，不能当作实景照片。当前不搜索或嵌入小红书、抖音、B 站视频，也不承诺一定有照片。

## 地点与图片可信度

- 景点和美食的本地缓存路径采用城市与名称安全映射，不直接把模型文本拼成文件路径。
- POI 结果需通过名称、城市及坐标范围检查；坐标格式为 `[经度, 纬度]`。无法核对时前端降级为名称搜索。
- 本地图片入缓存前会检查可解码性；索引记录来源类别、来源主机、核对时间和缓存期限，不保存外部图片 URL、Key 或签名。
- 远端坐标与图片分开记录期限（当前 30 天）；读取新鲜缓存不会把一次旧核对“续期”。缺图、过期、文件丢失/损坏和临时失败允许后续重新尝试，不写永久失败缓存。
- 用户自有或旧缓存若无法确认来源，会显示“来源未核实”；空图会显示本地占位图。

景点价格、营业时间、预约、无障碍设施和实际游览时长不是 POI 图片核验的一部分。行前应以景区或商家最新信息为准。
