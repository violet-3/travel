# 媒体匹配流程

## 图片搜索与匹配策略

```
获取景点列表 (含中英文名)
        │
        ▼
┌──────────────────┐
│ 1. Unsplash 搜索   │  英文名优先，中文名补充
│    返回: 3~5张     │
└────────┬─────────┘
         │
         ▼ 如果 Unsplash 无结果（小众景点/中国特有）
┌──────────────────┐
│ 2. 小红书搜索      │  景点名 + "拍照"/"打卡"
│    返回: 2~3篇笔记 │
└────────┬─────────┘
         │
         ▼ 如果小红书也少
┌──────────────────┐
│ 3. 百度图片搜索    │  Fallback 方案
│    返回: 1~2张    │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 4. 图片质量评估    │  分辨率 > 1200px, 无严重水印
│    + 去重         │
└────────┬─────────┘
         │
         ▼
   匹配到景点 + 标注来源
```

## 视频搜索策略

```
输入: 城市名 + "旅行攻略"
        │
        ▼
┌──────────────────┐
│ B站搜索 API       │  → 按播放量排序，取 top 1~2
│ 关键词: {城市}攻略 │
│ 过滤: 时长 5~30min│
└────────┬─────────┘
         │ 播放量 < 1000 或无结果
         ▼
┌──────────────────┐
│ 抖音/小红书短视频  │  短链接嵌入，适合分享
└──────────────────┘
```

## 图片下载与本地化

```python
async def download_and_cache(image_url: str, spot_name: str) -> str:
    """
    下载图片到 Obsidian vault 的附件目录
    返回: !image_name 格式的嵌入链接
    """
    cache_dir = "G:/AI_agent_space/AI-Agent-Space/_attachments"
    ext = image_url.split(".")[-1].split("?")[0]
    filename = f"{spot_name}_{uuid4().hex[:8]}.{ext}"
    
    async with httpx.AsyncClient() as client:
        resp = await client.get(image_url)
        with open(f"{cache_dir}/{filename}", "wb") as f:
            f.write(resp.content)
    
    return f"!{filename}"
```
