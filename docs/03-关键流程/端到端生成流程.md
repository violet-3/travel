## WebSocket 进度推送实现

```python
# FastAPI WebSocket 端点
@router.websocket("/ws/travel/{task_id}")
async def travel_progress(websocket: WebSocket, task_id: str):
    await websocket.accept()
    
    async def progress_callback(stage: str, progress: int, message: str, 
                                data: dict | None = None):
        """每个 Agent 完成后调用此回调推送进度"""
        payload = {
            "task_id": task_id,
            "stage": stage,
            "progress": progress,
            "message": message,
        }
        if data:
            payload["data"] = data  # 附加部分结果供前端预览
        
        await websocket.send_json(payload)
    
    # 执行生成流水线，注入回调
    result = await travel_pipeline.execute(
        intent=await websocket.receive_json(),
        on_progress=progress_callback,
    )
    
    await websocket.send_json({
        "progress": 100,
        "stage": "done",
        "result": result,
    })
```

## 前端消费进度

```javascript
// Vue3 组件
const progress = ref(0);
const stageMsg = ref('');
const partialResult = ref(null);

const ws = new WebSocket(`ws://localhost:8000/ws/travel/${taskId}`);

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    progress.value = data.progress;
    stageMsg.value = data.message;
    
    // 阶段完成时预览部分结果
    if (data.stage === 'route') {
        // 路线规划完成，可以预先渲染地图骨架
        partialResult.value = { route: data.data };
        renderMapPreview(data.data);
    }
    
    if (data.stage === 'done') {
        // 全部完成，展示最终结果
        showFullResult(data.result);
    }
};
```

## 失败处理

| 阶段失败 | 处理 |
|---------|------|
| 意图解析失败 | 终止，返回错误提示 |
| 路线规划失败 | 终止，提示"该目的地暂不支持" |
| 景点推荐超时 | 降级：用 LLM 内部知识 + 标注"建议出发前确认" |
| 风土人情失败 | 降级：输出基础版文化内容 |
| 媒体搜索超时 | 降级：攻略无图，文本仍可用 |
| 坐标补齐失败 | 降级：该地点在地图上显示在城市中心 |
| 质量校验不通过 | 自动修复一轮，仍不通过则标记"部分内容待确认" |
