# 当前端到端生成流程

> 本页描述当前 `app.py` / `orchestrator_llm.py` LangChain 主链。早期 Dify/WebSocket 工作流见项目历史文档，不适用于当前 API。

## 主流程

```text
Web / CLI 请求
  → 请求字段、旅行日期与硬约束校验
  → 捕获本次模型及高德配置快照
  → LangChain 意图解析 Agent
  → LangChain 路线规划 Agent
  → 景点推荐 Agent ∥ 城市文化 Agent
  → 路线/硬约束确定性检查
  → 高德 POI/图片富化 ∥ 按城市与日期查询天气
  → Python 预算计算和攻略编译
  → Web JSON / NDJSON 终态；或 CLI Markdown
```

其中意图、路线、景点与文化由同一请求级 `LLMClient` 共享。Agent 并行分支在失败、阶段超时或请求取消时会取消并等待剩余兄弟任务；编排器在结束时关闭可用的 provider SDK 根客户端。模型服务不会被静默替换为其他厂商。

## 阶段和降级

| 阶段 | 行为 |
|---|---|
| 意图解析 | 结构化输出 `TravelIntent`；确定性规则合并明确表单、日期与预算字段 |
| 路线规划 | 输出 `RoutePlan`；校验日期数、城市覆盖、顺序、交通方向和费用待核价状态 |
| 景点与文化 | 两个 Agent 并行；约束传入上下文，本地规则只提示明显冲突，不承诺证明事实正确 |
| POI 与图片 | 远端高德服务可用时校验地点名、城市与经纬度；缺配置、无匹配或获取失败时使用名称搜索/占位图 |
| 天气 | 只请求与目标路线日程对应的日期；缺 Key、范围外或请求失败时标注状态，不伪造预报 |
| 编译 | 计算人均已知费用和团体小计；待核价交通不计入确定小计，一日游住宿为 0 晚 |

LLM 阶段具有有界超时和 provider 配置的重试上限；地图/天气/图片阶段超时不会阻止文本攻略。耗时会记录；只有 provider 返回 token usage 时才显示 token 数，否则标注未知。

## Web NDJSON 协议

`POST /api/generate/stream` 每行一个 JSON 对象：

```json
{"type":"progress","progress":20,"stage":"route","message":"正在规划路线"}
{"type":"guide","guide":{"title":"安阳三日游"}}
```

一次请求以单个 `guide` 或 `error` 事件终止。前端处理 UTF-8 字节分块、最后无换行的事件，并拒绝坏 JSON、未知事件、缺少终态或终态后的额外事件。用户点击停止或关闭页面会中断浏览器请求；服务端检测到断连后取消生成任务。

成功攻略会原子写入本机 `guide-history.json`，最多 30 条。存储失败不影响当前攻略返回，但攻略会标记历史未保存。可在页面重新打开历史、导出 Markdown/JSON 或调用打印。

## 错误边界

- 旅行输入不合法：在发模型请求之前返回 422。
- 模型鉴权、模型不存在、限流或协议错误：返回固定安全提示，不回显 Key 或上游响应，也不自动切换服务商。
- 阶段超时：终止本次模型阶段，关闭已创建客户端，并返回明确的阶段超时提示。
- 用户取消/断连：取消编排任务和并行 Agent；取消的工作不会存为已完成攻略。
- 高德配置、POI、图片或天气不可用：文本和预算编译继续，相关信息显示缺失或待确认。
- 本机历史读写错误：历史 API 返回服务不可用状态；攻略生成不依赖历史文件可写。
