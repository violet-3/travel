# 媒体聚合器 (Media Aggregator)

## 职责

为攻略中的景点、美食、文化活动匹配图片和视频，嵌入最终 Markdown 输出。

## 媒体类型与策略

### 图片

| 类型 | 来源 | 说明 |
|------|------|------|
| 景点风景照 | Unsplash API | 免费高清，无水印 |
| 美食实拍 | 小红书爬取 | 接地气，但需注明来源 |
| 地图/路线图 | 高德静态地图 API | 生成路书式地图 |
| 文化元素 | 百度图片搜索 | 扎染/照壁/服饰等 |

### 视频

| 类型 | 来源 | 嵌入方式 |
|------|------|---------|
| 景点航拍 | B站搜索 API | iframe 嵌入播放器 |
| 美食探店 | 抖音/小红书 | 短链接跳转 |
| 文化纪录片 | B站/央视 | 免费正版节目链接 |

## 搜索策略

```
输入: 景点名 + 媒体类型
  │
  ├── "大理洱海 日出" → Unsplash: "Erhai Lake sunrise"
  │                   → 小��书: "洱海日出 拍照"
  │
  ├── "喜洲粑粑 美食" → Unsplash: (美食类图片少)
  │                   → 小红书: "喜洲粑粑 必吃"
  │
  └── "白族扎染 文化" → 百度图片: "白族扎染 制作"
                      → B站: "扎染 大理" → 视频嵌入
```

## 输出格式

```markdown
### 📸 洱海

!洱海日出.jpg
*龙龛码头日出，最佳拍摄时间 6:30-7:00 · 来源: Unsplash*
```

## 技术实现

```python
class MediaAggregator:
    def __init__(self):
        self.unsplash = UnsplashClient(api_key)
        self.xiaohongshu = XiaohongshuScraper()  # 需处理反爬
        self.amap = AmapStaticMap(api_key)
        self.bilibili = BilibiliSearch()

    async def search_for_spot(self, spot_name: str, media_types: list) -> MediaAssets:
        tasks = []
        if "photo" in media_types:
            tasks.append(self.unsplash.search(spot_name, count=3))
        if "food" in media_types:
            tasks.append(self.xiaohongshu.search_note(f"{spot_name} 美食", count=2))
        if "video" in media_types:
            tasks.append(self.bilibili.search(f"{spot_name} 旅行", count=1))

        results = await asyncio.gather(*tasks)
        return self.merge_assets(results)

    def build_route_map(self, daily_plan) -> str:
        """用高德静态地图 API 生成路线图"""
        markers = [day["city_center"] for day in daily_plan]
        return self.amap.static_map(markers, style="travel")
```
