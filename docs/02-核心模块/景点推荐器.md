# 景点推荐器 (Attraction Recommender)

## 职责

为路线中的每个城市推荐打卡地，分层输出：必去经典 + 小众宝藏 + 拍照机位。

## 三层推荐策略

```
每个城市的景点推荐:
┌──────────────────┐
│ Tier 1: 必去经典    │  ← 第一次来必打卡，通常 2~3 个
│ (大理古城/洱海)     │
├──────────────────┤
│ Tier 2: 深度体验    │  ← 有时间就去，3~5 个
│ (喜洲/双廊/寂照庵)   │
├──────────────────┤
│ Tier 3: 小众宝藏    │  ← 当地人才知道的，2~3 个
│ (龙龛码头日出)      │
└──────────────────┘
```

## 推荐因子

| 因子 | 权重 | 说明 |
|------|------|------|
| 知名度 | 25% | 搜索热度 / 社交媒体曝光 |
| 季节匹配 | 20% | 当前季节是否最佳观赏期 |
| 偏好匹配 | 25% | 与用户兴趣标签的重合度 |
| 体力消耗 | 15% | 是否匹配用户的 pace 设定 |
| 天气适宜 | 15% | 查询实时天气，雨天避开户外景点 |

  "name": "洱海",

## 季节性推荐示例

| 季节 | 适合去哪 | 不适合去哪 |
|------|---------|-----------|
| 春(3-5月) | 林芝桃花、婺源油菜花、扬州 | 东北（尚冷） |
| 夏(6-8月) | 青海湖、甘南、长白山、贵州 | 重庆/武汉（火炉） |
| 秋(9-11月) | 九寨沟、喀纳斯、额济纳胡杨林 | — |
| 冬(12-2月) | 哈尔滨冰雪、三亚、西双版纳 | 西藏（严寒封路） |

## 数据来源

| 来源 | 用途 |
|------|------|
| 马蜂窝/携程 | 景点基础数据 + 评分 |
| 小红书 | 小众机位 + 实时打卡情报 |
| 高德地图 | POI 坐标 + 开放时间 |
| RAG 知识库 | 历史攻略中的推荐排序 |

## 排序去重逻辑

```
1. 获取该城市所有候选景点（≈50个）
2. 按 tier 分层:
   - tier=1: 知名度前 10% 或 评分 > 4.5
   - tier=2: 知名度 10~30% 或 评分 4.0~4.5
   - tier=3: 低知名度但高评分，或有小红书爆款标签
3. 按用户偏好重新加权排序
4. 去重: 同类型景点（比如3个古城）最多保留 2 个
5. 输出 top 8~12 个，覆盖不同类型
```
