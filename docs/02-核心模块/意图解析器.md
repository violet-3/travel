# 意图解析器 (Intent Parser)

## 职责

将用户自由文本转换为结构化旅行意图。

## 输入输出

```
输入: "五一想去成都重庆玩5天，预算3000，带父母，不要太累"
  │
  ▼ 解析
输出: {
  "destinations": ["成都", "重庆"],
  "days": 5,
  "budget": 3000,
  "budget_level": "经济",
  "companion": "父母",
  "pace": "轻松",
  "preferences": [],
  "departure_city": null,
  "travel_date": "2026-05-01",
  "constraints": ["不爬山", "少走路"]
}
```

## 抽取维度

| 维度 | 字段 | 示例 |
|------|------|------|
| 目的地 | `destinations` | 云南 / 成都+重庆 / 江浙沪 |
| 天数 | `days` | 3 / 5 / 7~10 |
| 预算 | `budget` + `budget_level` | 3000(经济) / 8000(舒适) / 20000(豪华) |
| 同伴 | `companion` | 独自 / 情侣 / 朋友 / 父母 / 带娃 |
| 节奏 | `pace` | 特种兵 / 轻松 / 不紧不慢 |
| 偏好 | `preferences` | 自然风光 / 人文历史 / 美食 / 摄影 / 徒步 |
| 出发地 | `departure_city` | 北京 / 上海 / (为空则需追问) |
| 出行日期 | `travel_date` | 五一 / 国庆 / 春节 / 6月 |
| 硬约束 | `constraints` | 不爬山 / 不去高海拔 / 需要无障碍通道 |

## 缺失信息处理

```
优先级判断:
1. 目的地缺失 → 拒绝生成，要求指定
2. 天数缺失 → 默认 3 天
3. 预算缺失 → 默认中等
4. 偏好缺失 → 生成后再问"要不要加点自然风光/美食？"
5. 出发地缺失 → 不影响核心攻略，交通部分留空
```

## 提示词骨架

```
你是一个旅行意图解析专家。从用户的自由文本中提取结构化信息。

提取字段：目的地、天数、预算范围、同行人、旅行节奏、兴趣偏好、出发城市、出行日期、特殊约束。

规则：
- 目的地必须明确到城市级别
- 预算不明确时，标注为"未知"而不是猜测
- 节假日名称（五一/国庆）要转换为具体日期
- 约束从用户话术中推理（"带老人"→ 节奏轻松、不爬山）
```

## 边界处理

| 场景 | 处理 |
|------|------|
| 目的地不明确 | 追问："想去哪个省或城市？" |
| 目的地超出中国范围 | 提示："我目前专注于中国旅游攻略" |
| 完全无约束 | 给出默认轻松3日游，附"如需调整请告诉我偏好" |
