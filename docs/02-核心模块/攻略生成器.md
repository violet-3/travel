## 编译流水线

```
RoutePlan + SpotList + CultureData + MediaAssets
        │
        ▼
┌──────────────┐
│ 模板选择器     │  ← 根据天数/目的地特征选模板
└──────┬───────┘
       ▼
┌──────────────┐
│ 内容填充器     │  ← 合并多源数据填入模板槽位
└──────┬───────┘
       ▼
┌──────────────┐
│ 媒体嵌入      │  ← 图片本地化下载 + 视频链接嵌入
└──────┬───────┘
       ▼
┌──────────────┐
│ 质量检查      │  ← 完整性校验 / 一致性检查
└──────┬───────┘
       ▼
  Final Markdown → Obsidian Vault
```

## 输出模式

| 模式 | 命令 | 说明 |
|------|------|------|
| 完整攻略 | `travel generate` | 包含所有四要素的完整 Markdown |
| 路线速览 | `travel route` | 仅路线+景点，无文化和图片 |
| 文化专题 | `travel culture` | 仅风土人情深度内容 |
| 打卡清单 | `travel spots` | 纯景点列表 + 拍照机位 |
