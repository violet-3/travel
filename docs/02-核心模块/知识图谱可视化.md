# 知识图谱可视化 (Knowledge Graph)

## 职责

用 ECharts 力导向图展示「城市-天数-景点-预算」之间的关系网络，让用户从全局视角看懂一趟旅行。

## 为什么需要知识图谱

文本攻略是线性的，地图攻略是空间的，而**知识图谱是关系的**——它回答的是：

> "这个景点属于哪个城市？这一天花了多少钱？哪个城市的景点最多？"

## 图谱节点与边

```
节点类型:
├── 🏙️ 城市节点 (City)      — 大圆，蓝色
├── 📅 天数节点 (Day)        — 中圆，橙色  
├── 🏔️ 景点节点 (Spot)       — 小圆，绿色
├── 🍜 美食节点 (Food)       — 小圆，红色
├── 💰 预算节点 (Budget)     — 菱形，金色
└── 🎭 文化节点 (Culture)    — 菱形，紫色

边类型:
├── City → Day              — "在这一天"
├── Day → Spot              — "当天游览"
├── Day → Food              — "当天推荐吃"
├── Spot → Culture          — "景点关联文化"
└── Day → Budget            — "当天花费"
```

## 生成图谱数据

```python
class KnowledgeGraphBuilder:
    def build(self, travel_data: UnifiedTravelData) -> dict:
        nodes = []
        links = []
        
        # 城市节点
        for city in travel_data.route.cities:
            nodes.append({
                "name": city.name,
                "category": "city",
                "symbolSize": max(30, min(50, city.spot_count * 10)),
                "desc": f"{city.spot_count} 个景点"
            })
        
        # 每日节点 + 景点 + 美食
        for day in travel_data.daily_plan:
            day_node = f"Day{day.number}"
            nodes.append({"name": day_node, "category": "day"})
            links.append({"source": day.city, "target": day_node})
            
            for spot in day.spots:
                nodes.append({"name": spot.name, "category": "spot"})
                links.append({"source": day_node, "target": spot.name})
            
            for food in day.foods:
                nodes.append({"name": food.name, "category": "food"})
                links.append({"source": day_node, "target": food.name})
        
        return {"nodes": nodes, "links": links}
```

## 图谱交互

| 操作 | 效果 |
|------|------|
| 悬停节点 | 高亮该节点所有相邻节点 + 显示详情 tooltip |
| 点击城市 | 展开/收起该城市的所有日子和景点 |
| 双击节点 | 跳转到攻略中对应章节 |
| 拖拽节点 | 自由调整布局 |
| 滚轮缩放 | 放大/缩小 |

## 导出选项

- **导出 PNG** — 分享用
- **导出为 Obsidian 图谱数据** — 写入 `graph.json`，在 Obsidian 图谱视图中展示
