# 双模输出引擎 (DualMode Output)

## 职责

同一份旅行数据 → 两种输出形态：可交互地图路线 + 可阅读文本攻略。

## 核心概念

```
UnifiedTravelData（统一数据层）
        │
        ├──→ 路线图模式：GeoJSON → 高德地图渲染 → 交互式地图
        │
        └──→ 文本路线模式：Markdown 模板编译 → .md 文件
```

**关键原则**：两种模式共享同一份 `UnifiedTravelData`，不是两套系统，是一个系统的两种视图。

### GeoJSON 路线数据生成

```python
class MapRouteGenerator:
    """将路线规划结果转为 GeoJSON，供高德地图渲染"""
    
    def generate(self, route_plan: RoutePlan, spots: list[Spot]) -> dict:
        return {
            "type": "FeatureCollection",
            "features": [
                # 城市间连线
                {
                    "type": "Feature",
                    "geometry": {
                        "type": "LineString",
                        "coordinates": [
                            [102.834, 24.881],  # 昆明
                            [100.227, 25.607],  # 大理
                            [100.230, 26.865],  # 丽江
                            [99.701, 27.832]    # 香格里拉
                        ]
                    },
                    "properties": {
                        "type": "city_route",
                        "color": "#FF6B6B",
                        "width": 3,
                        "dash": "solid"
                    }
                },
                # 每天游览路线（不同颜色）
                *self._daily_routes(route_plan),
                # 景点 Marker
                *self._spot_markers(spots),
                # 美食点 Marker
                *self._food_markers(spots),
            ]
        }
    
    def _daily_routes(self, plan) -> list:
        """每天用不同颜色绘制景点间路线"""
        colors = ["#FF6B6B", "#4ECDC4", "#45B7D1", "#96CEB4",
                  "#FFEAA7", "#DDA0DD", "#FF8C00"]
        routes = []
        for day in plan.daily_plan:
            coords = [spot.coordinate for spot in day.spots]
            routes.append({
                "type": "Feature",
                "geometry": {"type": "LineString", "coordinates": coords},
                "properties": {
                    "type": "daily_route",
                    "day": day.day_number,
                    "color": colors[day.day_number - 1],
                    "label": f"Day {day.day_number}"
                }
            })
        return routes
```

### 前端渲染代码（高德地图）

```javascript
// 初始化高德地图
const map = new AMap.Map('map-container', {
    zoom: 9,
    center: [102.834, 24.881],  // 云南中心
    mapStyle: 'amap://styles/light',
});

// 加载 GeoJSON 路线数据
const geoData = await fetch('/api/route/geojson').then(r => r.json());

// 绘制城市间路线
geoData.features
    .filter(f => f.properties.type === 'city_route')
    .forEach(f => {
        const polyline = new AMap.Polyline({
            path: f.geometry.coordinates,
            strokeColor: f.properties.color,
            strokeWeight: 3,
            strokeStyle: 'solid',
        });
        map.add(polyline);
    });

// 绘制景点 Marker（聚合显示）
const markers = geoData.features
    .filter(f => f.properties.type === 'spot')
    .map(f => {
        const marker = new AMap.Marker({
            position: f.geometry.coordinates,
            title: f.properties.name,
            label: { content: f.properties.day_label, offset: new AMap.Pixel(0, -20) },
        });
        // 点击弹出详情
        marker.on('click', () => showSpotCard(f.properties));
        return marker;
    });

// 左侧面板联动
document.querySelectorAll('.day-tab').forEach(tab => {
    tab.addEventListener('click', () => {
        const day = tab.dataset.day;
        map.setFitView(markers.filter(m => m.properties.day === day));
        highlightDayRoute(day);
    });
});
```

## 模式二：📝 文本路线模式

### Markdown 编译引擎

```python
class MarkdownCompiler:
    """将 UnifiedTravelData 编译为完整 Markdown 攻略"""
    
    TEMPLATE = """
# 《{title}》
> {subtitle}

## 📋 速览
{brief_table}

## 🗺️ 路线总览
{route_overview}

## 📅 每日详情
{daily_sections}

## 🎭 风土人情
{culture_sections}

## 📸 摄影师机位清单
{photo_spots}

## 💰 预算明细
{budget_table}

## ⚠️ 注意事项
{warnings}

## 📱 实用工具
{tools}

{media_embeds}

---
*攻略由 TravelAgent AI 生成 · {date}*
"""
    
    def compile(self, data: UnifiedTravelData, mode: str = "full") -> str:
        if mode == "full":
            return self._compile_full(data)
        elif mode == "route_only":
            return self._compile_route_only(data)
        elif mode == "culture_only":
            return self._compile_culture_only(data)
        elif mode == "spots_only":
            return self._compile_spots_only(data)
```

### 输出模式子命令

```bash
# CLI 命令
travel generate --mode map     # 🗺️ 输出路线图（打开浏览器/导出HTML）
travel generate --mode text    # 📝 输出文本攻略（Markdown）
travel generate --mode both    # 两种都输出（默认）
travel generate --map-only     # 仅路线图
travel generate --text-only    # 仅文本攻略
```

## 模式切换机制

### Web UI 中的一键切换

```javascript
// Vue3 组合式 API
const outputMode = ref<'map' | 'text'>('map');

const toggleMode = () => {
    outputMode.value = outputMode.value === 'map' ? 'text' : 'map';
    // 两种模式数据共享，切换无延迟
};

// 模板中的条件渲染
<template>
    <div class="output-container">
        <!-- 路线图模式 -->
        <MapView v-if="outputMode === 'map'" :geoData="travelData.geo_route" />
        
        <!-- 文本路线模式 -->
        <MarkdownView v-else :content="travelData.markdown" />
        
        <!-- 切换按钮 -->
        <button class="mode-toggle" @click="toggleMode">
            {{ outputMode === 'map' ? '📝 切换文本路线' : '🗺️ 切换路线图' }}
        </button>
    </div>
</template>
```

## 两种模式对比

| | 🗺️ 路线图模式 | 📝 文本路线模式 |
|------|------|------|
| **最佳场景** | 出发前路线预览、分享给同伴 | 深度阅读、收藏、打印 |
| **核心优势** | 空间感强、路线一目了然 | 信息密度高、可搜索编辑 |
| **依赖** | 需要浏览器/App | 任何 Markdown 阅读器 |
| **离线** | 高德离线地图 | ✅ 天然离线 |
| **分享** | 分享链接/截图 | 分享 .md 文件 |
| **数据量** | GeoJSON ≈ 50~200KB | Markdown ≈ 20~50KB |
