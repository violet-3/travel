# 路线规划器 (Route Planner)

## 职责

根据解析出的意图，生成多日行程骨架——每天去哪个城市/区域，上午下午晚上分别做什么。

## 核心能力

1. **城市组合推荐**：给定目的省份，自动推荐经典线路（如云南：昆大丽香）
2. **日行程分配**：按天数切分城市，每天 3 个时段各 1~2 项
3. **交通衔接**：城市间交通方式（高铁/大巴/自驾）和时间
4. **节奏控制**：根据 `pace` 参数调节每日项目密度

## 算法逻辑

```
输入: destinations=["云南"], days=7, pace="不紧不慢"

Step 1: 匹配目标省份 → 检索路线模板库
Step 2: 返回候选路线:
  Template A: 昆明(2天) → 大理(2天) → 丽江(2天) → 返程(1天)
  Template B: 昆明(1) → 大理(2) → 丽江(2) → 香格里拉(1) → 返程(1)
  Template C: 腾冲(2) → 大理(2) → 丽江(3)
Step 3: 根据 preferences(自然风光+美食) → 选择 Template B（香格里拉加分）
Step 4: 填充每日内容

输出骨架:
Day 1: 抵达昆明 → 翠湖公园 → 南强街夜市
Day 2: 石林风景区 → 动车去大理(2h) → 大理古城夜游
Day 3: 环洱海(租车) → 喜洲古镇 → 双廊日落
Day 4: 大理→丽江(高铁1.5h) → 丽江古城 → 四方街
Day 5: 玉龙雪山(蓝月谷) → 印象丽江演出
Day 6: 丽江→香格里拉(大巴3h) → 独克宗古城 → 转经筒
Day 7: 普达措国家公园 → 返程
```

## 节奏调节

| pace 值 | 每日项目数 | 示例 |
|---------|-----------|------|
| 特种兵 | 4~6 项 | 一天打卡 5 个景点 |
| 不紧不慢 | 3~4 项 | 上午1景点 + 下午1景点 + 晚上美食 |
| 轻松 | 2~3 项 | 上午自然醒 + 1个核心景点 + 自由探索 |

## 依赖工具

| 工具 | 用途 |
|------|------|
| `search_route_templates` | 从 RAG 知识库检索经典路线 |
| `search_transport` | 查询高铁/大巴班次和耗时 |
| `get_distance` | 计算城市间距离 |
| `check_season` | 判断季节适宜性（雨季/封山/花期） |

## 季节约束

```
需要检查的约束:
- 玉龙雪山：雨季(6-8月)能见度低，冬季(12-2月)可能封山
- 稻城亚丁：最佳 5-10月，冬季关闭
- 青海湖：最佳 7-8月油菜花期
- 哈尔滨冰雪大世界：仅 12-2月开放
- 林芝桃花：仅 3月下旬-4月中旬
```

## 🗺️ 坐标补齐策略

```python
class CoordinateEnricher:
    """为路线中的每个地点补齐经纬度"""
    
    def enrich(self, route_plan: dict) -> dict:
        for day in route_plan["daily_plan"]:
            # 城市中心坐标：从高德行政区划查询
            day["city_center"] = self.amap.district(day["city"]).center
            
            for slot in ["morning", "afternoon", "evening"]:
                place_name = day[slot]["activity"]
                # 从高德 POI 搜索获取精确坐标
                coord = self.amap.poi_search(place_name, city=day["city"])
                day[slot]["coordinate"] = coord or day["city_center"]
            
            # 住宿区域坐标
            day["stay_coordinate"] = self.amap.poi_search(
                day["stay"], city=day["city"]
            )
        
        for t in route_plan["transport"]:
            t["from_coord"] = self.amap.poi_search(t["from"] + "站")
            t["to_coord"] = self.amap.poi_search(t["to"] + "站")
        
        return route_plan
```
