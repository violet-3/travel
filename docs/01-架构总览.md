## 双模输出数据结构

```python
class UnifiedTravelData:
    """
    所有 Agent 产出的统一数据结构
    路线图模式和文本路线模式共享同一份数据
    """
    # 元信息
    destination: str
    days: int
    budget_level: str
    
    # 地图数据（路线图模式使用）
    geo_route: GeoJSON          # 完整的路线 GeoJSON
    
    # 文本数据（文本路线模式使用）
    daily_plan: list[DayPlan]   # 每日行程详情
    
    # 共享数据（两种模式都用）
    spots: list[Spot]           # 景点（含经纬度/图片/评分）
    culture: CultureData        # 风土人情
    media: MediaAssets          # 图片视频素材
    budget: BudgetBreakdown     # 预算明细
```

## 路线图模式技术选型

| 层级 | 方案 A (推荐) | 方案 B (备选) |
|------|-------------|-------------|
| 地图引擎 | **高德地图 JS API 2.0** | Leaflet + OpenStreetMap |
| 路线绘制 | AMap.Polyline + AMap.Marker | Leaflet Routing Machine |
| POI 标注 | AMap.MarkerClusterer (聚合) | Leaflet.markercluster |
| 交互 | 点击 POI 弹出详情卡片 | 侧边栏同步高亮 |
| 国内使用 | ✅ 高德数据最全 | ⚠️ OSM 国内数据弱 |
| 离线支持 | 高德离线地图 SDK | — |

### 路线图模式的输出

```
高德地图上显示:
1. 城市间连线（高铁/自驾路线）→ 不同颜色区分
2. 每天景点 Marker → 数字标注 Day1 Day2...
3. 点击 Marker 弹出 Popup: 名称/图片/游览时长/评分
4. 左侧日程面板：天级 Tab 切换，点击高亮对应 Marker
5. 底部预算条：累计花费实时更新
```
