# 山河游记 · 已批准的十轮迭代方案

用户已审核方案并授权“开始实现”，后续再次要求继续。逐轮由实现工程师修改，决策复核官独立检查，通过后继续；无需每轮重新向用户申请实施许可。

## 交付范围

本地个人版，沿用 FastAPI、LangChain 和原生 HTML/CSS/JS。用户能在页面填写厂商、API Key、Base URL、模型名称，保存/编辑/删除/选择命名配置，生成中国旅行攻略。支持 OpenAI 兼容协议及 Claude、Gemini 原生协议；地图、POI、天气服务独立配置，缺少服务 Key 时仍可用文本攻略。保留 Web、CLI、现有视觉风格和合理的降级。

此阶段不扩展公网多租户、账号支付、机票酒店交易或复杂知识图谱；不提交、合并或发布。不得覆盖原有用户未提交改动。真实模型/高德调用尚未安排；使用 mock 与临时数据进行测试，不读取或改写真实凭据，不将离线通过写成真实厂商已验证。

## 轮次与验收

| 轮次 | 交付内容 | 主要验收标准 |
| --- | --- | --- |
| 1 | 修复景点/文化结构化返回，隔离冒烟测试，记录迁移差异 | typed 模型、items 字典、列表、完整 JSON 内容保留；空/截断/无名记录明确失败；不联网、不污染照片缓存 |
| 2 | 不可变 ModelConfig、工厂、Web/CLI 请求级注入 | 并发不同模型/URL/Key 不串用；运行期间默认配置变更不改变快照；环境变量兼容；密钥脱敏 |
| 3 | 设置页、命名配置、默认配置、系统凭据保存、显式临时模式 | 重启恢复、编辑留空 Key 保留、明确清除/删除、失败回滚、本机 Host/Origin 限制；手机可输入和操作 |
| 4 | 常用预设、自定义接口、三协议原生适配、连接与结构化诊断 | 模型可手填；无 /models 仍可用；按显式点击诊断；错误分类且不回显秘密；诊断状态与配置一致；跨厂商/主机修改须重填或清除 Key |
| 5 | 可选结构化旅行表单、日期/人数/预算口径、意图上下文传递 | 只有明确填写的表单字段覆盖自由文本；Asia/Shanghai 日期基准；非法日期/人数/天数/金额安全报错；不辣/不爬山等约束传到相关 Agent；显示实际需求摘要 |
| 6 | 确定性行程与预算校验 | 天数、编号、城市覆盖、跨城安排一致；一日游不无条件计住宿；无固定往返交通加项；分项合计一致；人均/总额/人数/晚数/估算口径清楚；不能满足的预算或约束不冒充已满足 |
| 7 | 主链路地图、POI、天气闭环与服务设置 | 校验同名地点、城市与经纬度；每日景点地图和行程联动；城市连线不冒充道路路线；天气字段一致、范围外不造预报；拆开前端 JS 安全码与后端签名密钥；缺 Key 降级 |
| 8 | 图片来源、事实状态、缓存恢复与路径边界 | 实拍/地图/占位区分；来源和查询时间可辨；错误或过期缓存可恢复；原子/并发写入不损坏索引；城市与名称不能越界写文件；未核验事实不冒充实时权威信息 |
| 9 | 生成可靠性、本地历史与导出 | 保留 NDJSON；可取消、阶段超时、有界重试、错误后 UI 恢复；任务和 HTTP 资源清理；可获得的耗时/用量；历史重启可读；Markdown/JSON/打印可用且不含凭证；不偷偷换付费厂商 |
| 10 | 端到端与安装交付 | 固定场景回归；从空配置到导出验证；桌面与手机检查；启动、配置、兼容版本、迁移恢复、限制说明；真实服务与 mock 验证分别记录，无未解决的交付阻断 |

## 固定验收场景

单城三日、多城七日、一日游、亲子、老人少步行、低预算、跨年日期、无地图 Key、错误模型 Key、限流、取消、并发切换配置。校验行为采用可复现 fixture；真实厂商联调只在有实际条件时单独记录，否则明确未实测。
