# 第十九至二十一轮实施记录：DeepSeek 网页资料补全

## 目标与结果

保留现有 LangChain 旅游攻略生成主链，在生成景点与文化内容、完成高德 POI 富化后，提供可选的 DeepSeek Search/Fetch 信息补全。网页、CLI 和导出结果会显示来源、抓取时间、票价原文线索与图片候选。默认不开启联网请求。

DeepSeek 官方 Search/Fetch 接口与计费以[官方文档](https://api-docs.deepseek.com/zh-cn/guides/search/)为准：Search 和 Fetch 使用独立 HTTP 端点；文档列出的价格为每 1000 次成功且非空请求 ¥5。当前限制为最多 3 个景点、每个景点最多 1 次 Search 和 1 次 Fetch、并发上限 2、每次请求最多 12 秒、整个联网阶段最多 42 秒，不重试请求。单个攻略最多 6 次 Search/Fetch 请求，文档费率下最多约 ¥0.03。

## 第十九轮：配置、凭据与请求边界

- 增加独立的联网资料设置和状态接口：`GET/PUT/DELETE /api/deepseek-search-settings`。状态只报告开关、凭据是否存在、服务地址来源与可选官方档案，不回显密钥。
- 默认模式为关闭。可显式选择 `provider=deepseek`、OpenAI 兼容协议、服务主机为 `api.deepseek.com` 的模型档案；其他档案不会被自动用于 Search。也可选择独立 Search Key。
- 配置元数据保存在用户目录 `deepseek-search-settings.json`；独立密钥存入系统凭据库，或由用户明确选为“仅本次运行”时留在进程内存。会话密钥写入失败不改变已有来源、主机或密钥快照；切换来源和清除设置会同步处理旧的持久密钥。
- `.env` 独立凭据模式需要显式设置 `DEEPSEEK_SEARCH_ENABLED=true`、`DEEPSEEK_SEARCH_AUTH_MODE=dedicated` 和 `DEEPSEEK_SEARCH_API_KEY`。只设置 Key 不会启用联网。环境地址覆盖主机时，旧主机的保存密钥不会复用；只有为新主机另行配置的环境密钥才可使用。
- 状态接口会标出被环境变量覆盖的字段，设置页对应禁用这些控件；环境锁定官方档案模式时，仍可在页面明确选择具体档案。清除操作说明只删除本地设置和系统凭据，不更改系统环境变量。
- Search/Fetch 请求使用无重定向、有限响应大小和安全错误分类的 HTTP 客户端；HTTP 401、402、403、429、无效格式、超时和网络失败均停止当前景点请求，不无限重试，也不把原始响应错误或密钥写入攻略。

## 第二十轮：主链来源与图片闭环

- 联网补全在模型生成与高德富化之后、可执行性分析和攻略编译之前运行。网页正文只进入确定性解析与输出数据，不再传给另一个 LLM。
- 搜索结果需在标题、摘要或 URL 主机/路径中匹配城市和景点名；URL 查询参数不用于地点归属。Fetch 正文必须再次包含目标城市和景点名，否则只保留搜索来源，不提取该页价格、开放时间或图片。
- 门票、开放时间和预约摘录由原文逐行截取，来源 ID 对应实际来源 URL。常见景点标题下的“门票”“开放时间”等通用子章节会沿用景点上下文。价格仍标为网页线索，票种/日期/身份条件待核实，不覆盖模型参考价或预算。来源机构、官方性和权威分数不会被自动认定。
- Search 来源、Fetch 状态、抓取时间、搜索摘要与页面原文保存在 `TravelGuide.web_research.spots`，避免把工具专属引用字段加入 LangChain `Spot` 输出 schema。旧历史和缓存没有该字段时，默认呈现“未联网检索”。
- Fetch 正文只提取 Markdown 图片和 HTML `<img>`。明显 logo、favicon、二维码与图标候选会被跳过；候选链接始终保留来源页关联和未核验说明，不直接成为远程 `<img>`。
- 每个景点最多尝试下载一张图片，优先 alt 中包含景点名的候选。图片下载不带 DeepSeek Authorization；请求前解析并验证公网 IP，连接固定到已校验 IP，保留原 Host、TLS SNI 与证书校验；每次重定向重新检查目标，禁用系统代理，限制为 HTTPS、3 次重定向、5 MiB、8 秒、受支持的光栅 MIME 和 Pillow 解码校验。验证后的文件原子写入 `static/photos/web-research/`。下载失败时回退展示来源页链接；下载成功也注明图片内容、景点关联和授权未经核验，不覆盖高德实景图片。

## 第二十一轮：缓存、前端与回归

- Search 启用状态、端点/配置身份、版本和密钥单向摘要参与缓存键；启用、关闭或密钥变更不会互相复用结果。密钥原文不进入缓存键输入、API 响应、历史或日志。
- 网页景点页、Markdown、JSON 与历史都携带联网状态和来源。概览对缓存命中注明联网统计属于原攻略；缓存提示明确说明本次没有新增模型或 Search/Fetch 请求。设置档案列表会在模型档案新建、编辑或删除后即时更新，并保留未提交的联网设置输入。
- CLI 支持 `--web-research` 和 `--no-web-research` 单次覆盖；默认读取本机联网设置。没有 Search 凭据时继续生成文本攻略并显示不可用状态。
- README 与 `.env.example` 已补充开关、Key 来源、单次请求上限、费用提示、数据保存位置和真实 API 未验收的边界。
