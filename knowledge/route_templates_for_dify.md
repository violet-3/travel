# 云南经典路线

## 昆大丽香 7 日经典线
- 天数: 7天
- 城市: 昆明 → 大理 → 丽江 → 香格里拉
- 节奏: 不紧不慢
- 适合: 自然风光、人文历史、摄影
- 最佳季节: 4-5月 / 9-11月
- 交通: 昆明→大理 动车2h ¥145, 大理→丽江 动车1.5h ¥80, 丽江→香格里拉 大巴3h ¥60
- 亮点: 洱海骑行、玉龙雪山、独克宗古城、普达措
- 提醒: 香格里拉海拔3300m注意高反, 玉龙雪山大索道需提前3天20:00抢票
- 每日梗概:
  Day1 昆明: 抵达→翠湖公园→南强街夜市
  Day2 昆明→大理: 石林(可选)→动车去大理→大理古城夜游
  Day3 大理: 环洱海骑行→喜洲古镇→双廊日落
  Day4 大理→丽江: 动车→丽江古城→四方街→大水车
  Day5 丽江: 玉龙雪山(蓝月谷)→印象丽江演出
  Day6 丽江→香格里拉: 大巴→独克宗古城→转经筒→龟山公园
  Day7 香格里拉: 普达措国家公园→返程

## 昆明大理丽江 5 日精华线
- 天数: 5天
- 城市: 昆明 → 大理 → 丽江
- 节奏: 不紧不慢
- 适合: 自然风光、休闲、美食
- 交通: 昆明→大理 动车2h, 大理→丽江 动车1.5h
- 亮点: 洱海、大理古城、丽江古城、玉龙雪山
- 每日梗概:
  Day1 昆明: 抵达→翠湖公园→南强街夜市
  Day2 大理: 动车抵达→大理古城→人民路
  Day3 大理: 环洱海→喜洲→双廊
  Day4 丽江: 动车抵达→丽江古城→木府→四方街
  Day5 丽江: 玉龙雪山→蓝月谷→返程

## 西双版纳 4 日热带风情线
- 天数: 4天
- 城市: 西双版纳(景洪)
- 节奏: 轻松
- 适合: 自然风光、少数民族文化、亲子
- 最佳季节: 11-2月(避开雨季)
- 亮点: 中科院热带植物园、野象谷、告庄西双景、傣族园
- 提醒: 4-10月雨季蚊虫多

# 四川经典路线

## 成都及周边 5 日休闲线
- 天数: 5天
- 城市: 成都 → 都江堰 → 乐山
- 节奏: 不紧不慢
- 适合: 美食、人文历史、休闲
- 交通: 成都→都江堰 城际30min ¥10, 成都→乐山 高铁1h ¥54
- 亮点: 大熊猫基地、都江堰、乐山大佛、宽窄巷子、锦里
- 每日梗概:
  Day1 成都: 抵达→宽窄巷子→锦里
  Day2 成都: 大熊猫繁育基地→文殊院→春熙路
  Day3 都江堰: 城际→都江堰景区→青城山
  Day4 乐山: 高铁→乐山大佛→张公桥美食街
  Day5 成都: 人民公园喝茶→返程

## 川西大环线 8 日深度线
- 天数: 8天
- 城市: 成都 → 康定 → 新都桥 → 稻城 → 色达
- 节奏: 特种兵
- 适合: 自然风光、摄影、徒步
- 最佳季节: 5-10月
- 提醒: 稻城亚丁海拔4700m, 色达佛学院需提前预约

# 西北经典路线

## 青甘大环线 7 日经典线
- 天数: 7天
- 城市: 西宁 → 青海湖 → 茶卡 → 大柴旦 → 敦煌 → 张掖 → 西宁
- 节奏: 不紧不慢
- 适合: 自然风光、摄影、人文历史

# 华东经典路线

## 江南水乡 5 日柔情线
- 天数: 5天
- 城市: 杭州 → 苏州 → 乌镇 → 上海
- 节奏: 轻松
- 适合: 人文历史、美食、休闲
- 交通: 杭州→苏州 高铁1.5h, 苏州→上海 高铁30min
- 亮点: 西湖、苏州园林、乌镇水乡、外滩
- 每日梗概:
  Day1 杭州: 西湖→断桥→雷峰塔→河坊街
  Day2 杭州: 灵隐寺→龙井村→钱塘江
  Day3 苏州: 高铁→拙政园→平江路→山塘街
  Day4 乌镇: 大巴→西栅→夜游水乡
  Day5 上海: 高铁→外滩→南京路→返程
